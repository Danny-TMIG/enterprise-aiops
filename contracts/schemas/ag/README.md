components.

## Relationship to canonical schemas

Canonical schemas live at `40_CROSS_STACK_INTEGRATION/05_Canonical_Schemas/`
and `contracts/canonical/`. Layer-local schemas in this directory are
Govern-layer projections of canonical objects. Any change here has
cross-layer effect and requires review.
