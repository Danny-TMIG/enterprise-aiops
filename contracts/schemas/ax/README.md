# contracts/schemas/ax/

## What is here

JSON Schema definitions for objects emitted or consumed by **Cognition**
components.

## Relationship to canonical schemas

Canonical schemas live at `40_CROSS_STACK_INTEGRATION/05_Canonical_Schemas/`
and `contracts/canonical/`. Layer-local schemas in this directory are
projections of canonical objects, adapted for use inside the Cognition
layer. They must conform to the canonical definitions; they may not expand
authority, weaken classification, remove evidence obligations, or alter
failure semantics.

## Current state

Empty. Cognition-layer schema projections have not been authored.
