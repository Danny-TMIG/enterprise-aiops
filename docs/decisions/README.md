# docs/decisions/

## What is here

Architecture Decision Records (ADRs). One file per decision.

## Format

Each ADR records:

- The question
- The options considered
- The choice
- The consequences

## Rules

- ADRs are **immutable after acceptance**. A decision that changes is
  superseded by a new ADR that references the old one.
- Numbering is sequential. `0001-*.md`, `0002-*.md`, etc.
- The ADR index (this file) lists every ADR with a one-line summary.

## Relationship to the FAS open decisions

Every `GOV-DEC-*`, `CMP-DEC-*`, and `COG-DEC-*` that closes gets an ADR
here recording the resolution. The FAS tracks the question; the ADR
records the answer.
