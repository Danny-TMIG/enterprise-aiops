# Decision records

Architecture decision records (ADRs) for Aether Fabric.

## Format

    {
      "id": "GOV-DEC-014",
      "title": "...",
      "status": "accepted",
      "date": "YYYY-MM-DD",
      "context": "...",
      "decision": "...",
      "consequences": ["..."]
    }

## Prefixes

- CMP-DEC-*  Aether Compute
- COG-DEC-*  Aether Cognition
- GOV-DEC-*  Aether Govern

Historical records under _archive/decisions/.
